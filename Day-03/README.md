# Day-03 — Data Analysis & Python for AI/ML

## Project Overview

Day-03 focuses on learning Data Analysis and Python concepts used in AI/ML.

In this project, a facility dataset is inspected, cleaned, analyzed, and visualized using Python libraries such as NumPy, Pandas, and Matplotlib.

The project demonstrates how to work with real-world data containing missing values, duplicate records, invalid values, and outliers.

## Objectives

The main objectives of Day-03 are:

- Learn NumPy arrays and operations.
- Learn Pandas Series and DataFrames.
- Read and analyze CSV files.
- Identify missing values.
- Identify duplicate records.
- Identify invalid data.
- Handle missing and invalid values.
- Detect outliers using the IQR method.
- Perform data analysis using Pandas.
- Perform mathematical operations using NumPy.
- Create visualizations using Matplotlib.
- Generate useful insights from the dataset.
